## 4. 运维铁律（r9 阵亡事故的教训）

1. **一场一管**：编队运行期间，宿主**禁止**任何会拉起 LoopX effect runtime 的活动
   （pytest 套件/考场重建/demo 验证）。r9 实证：修复轮的 effect runtime 启动死线
   被并发 pytest 顶爆（22:14 同秒撞车），两轮耗尽=九场首例中途死亡。
2. 新底座冷启动更重（planner +17%），启动死线对竞争更敏感——铁律只紧不松。
3. 端点按 SDK 版本强配对（守卫已实现），模板/守卫/venv 三方同改（死锁三件套教训）。
